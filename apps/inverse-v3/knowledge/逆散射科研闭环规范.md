# 逆散射科研闭环规范

## 1. 项目定位

本项目是仿体约束逆散射重建仿真验证研究。核心目标：通过仿体先验几何约束解决逆散射多解性问题——将有效自由度从 ~500 B-spline 参数降低到 ~48 个有效约束，使欠定方程组变为适定。

## 2. 核心物理参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 散射体球半径 | 0.13m | 研究对象 |
| 测量球面半径 | 0.26m | S21 采样面 |
| 工作频率 | 0.8-1.0 GHz | 微波频段 |
| 光锥方向采样 | 64 | Fibonacci 球面 |
| 测量点数 | 4608 | 48θ × 96φ |
| 内部体素 | 673 | FEM 网格 |
| B-spline 最大控制点 | 500 | 10×10×5 |

## 3. 三件套评估指标

| 指标 | 含义 | 计算 |
|------|------|------|
| cos θ | J_obs vs J_hyp 方向一致性 | mean(dot(J_obs, J_hyp) / (‖J_obs‖·‖J_hyp‖)) |
| F_cheb | Chebyshev 残差 | η·max(F_k) + (1-η)·mean(F_k) |
| PASS 计数 | A12/C01 通过项数 | N/7 或 N/6 |

## 4. 反演方法

- **伴随梯度法**：解析 Maxwell 伴随源，手动推导梯度
- **B-spline 参数化**：将 673 体素压缩为少量控制点
- **正则化**：Tikhonov / TV / Chebyshev 加权

## 5. 工具链

- COMSOL 6.2 + MATLAB R2023b LiveLink（端口 2036）
- COMSOL Server 需独立终端长期运行（非 MCP 临时启动）
- 统一实验入口：`run_experiment('plugin_name')`
- 插件随插随用：`config.m` 中 `p.inversion_plugin = 'plugin_a12'`

## 6. 迭代参数参考（config.m）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| max_iter | 10 | 最大迭代次数 |
| eps_tol | 0.2 | 残差收敛阈值 |
| mu_init | 0.05 | 初始步长 |
| weight_strategy | 'uniform' | 加权策略（uniform/adaptive/chebyshev） |
| chebyshev_eta | 0.1 | Chebyshev 软最大化系数 |

## 7. 常见假设维度（研究者参考）

- B-spline 控制点密度（n_cx/n_cy/n_cz）
- 正则化强度（TV λ、Tikhonov 系数）
- 代价函数加权策略（uniform/adaptive/chebyshev）
- 线搜索步长策略
- J_hyp 模型（Born vs Full Maxwell）
- 新建/切换反演插件
