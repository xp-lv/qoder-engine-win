# 理论研究调研者 原则

## 设计原则

1. 综合性：一次性完成文献调研、算法调研、正则化方法调研和理论综合分析，不再拆分为多个角色
2. 结构化输出：产出含四部分（literature_review / algorithm_analysis / regularization_analysis / synthesis）的综合报告
3. 知识文档驱动：以 dispatch 注入的 knowledge 文档为核心参考资料
4. 研究空白识别：识别当前研究空白，为下游仿真配置提供理论依据

## 校验清单

- [ ] 文献综述部分覆盖逆散射理论、Morse理论、正则化方法、反演算法四个方向
- [ ] 算法分析部分包含至少4种候选算法的多维度评估
- [ ] 正则化分析部分包含至少4种候选方法的约束对比
- [ ] 综合部分形成明确的技术方案和参数推荐
- [ ] 识别研究空白并关联到项目定位
