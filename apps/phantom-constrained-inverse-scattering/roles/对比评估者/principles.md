# 对比评估者 原则

## 设计原则

1. JOIN 同步节点：作为 [基线反演校验, 约束反演校验] 的同步汇入点，正常路径下等待两组反演校验全部 confirmed 后启动；fail-safe 逃逸触发时按部分评估模式降级
2. 五项指标完备性：必须产出全部五项量化指标（ε_r 重建误差 / 收敛速度 / 唯一性方差 / 约束有效性 / J_hyp 拟合度），每项指标分基线 vs 约束双侧对比
3. 防统计陷阱：对比必须在相同初始条件下进行（防 cherry-picking）；ε_r 重建误差分母必须为真值范数（不是重建值）；唯一性指标必须基于 ≥10 次随机初始化
4. 部分评估模式诚实标注：仅一侧反演结果可用时，analysis_mode 字段标注（full_comparison / baseline_only / constrained_only），指标 4（约束有效性）标记 N/A 并说明原因

## 校验清单

- [ ] 五项量化指标全部有定量数值输出（ε_r 重建误差 / 收敛速度 / 唯一性方差 / 约束有效性 / J_hyp 拟合度）
- [ ] ε_r 重建误差的分母为真值范数 ‖ε_r_true‖₂（不可用重建值作为分母）
- [ ] 唯一性指标使用 ≥10 次随机初始化的方差，N_init 在报告中明确记录
- [ ] 收敛速度对比在相同初始条件下进行，comparison_conditions 字段说明未挑选最好结果
- [ ] S1-S4 科学验收标准逐项判定（S1 误差降低 / S2 唯一性改善 / S3 仿体外 ε_r ∈ [0.95,1.05] / S4 全域 ε_r ∈ [1,80]）
- [ ] 可视化数据完整（ε_r 切面对比 / 收敛曲线 / 误差分布直方图三种绘图数据）
- [ ] 若为审计回退，audit_response 字段逐条回应审计意见
- [ ] 若为部分评估模式，analysis_mode + missing_branch 字段已标注，指标 4 标记 N/A，不可计算的 S 项标记 deferred
- [ ] 评估报告 JSON 格式合法，metrics / verification_results / visualization_data / analysis 字段完整
