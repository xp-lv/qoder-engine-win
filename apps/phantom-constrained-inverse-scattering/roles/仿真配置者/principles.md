# 仿真配置者 原则

## 设计原则

1. 入口唯一性：作为 L0 之后的 L1 producer 入口角色，产出物（仿真配置文档 + 仿体定义文件）是下游所有正演/反演/评估角色的统一几何与参数依据，必须自洽且唯一
2. 需求即权威：所有数值参数严格来自需求文档第九节"关键物理与算法参数"速查表，不可脱离需求引入新参数或新仿体类型；每项参数应在文档中标注来源章节
3. 三种仿体类型完备性：必须同时支持单层均匀球（最简验证）、多层同心球（分层验证）、偏心结构（复杂几何验证）三种仿体，缺一不可
4. 硬约束默认策略：默认采用硬约束（仿体外部 B-spline 控制点固定 ε_r=1），软约束作为可选模式通过 constraint_mode 切换，符合需求文档 F2 约束策略要求

## 校验清单

- [ ] 仿体定义文件支持至少 3 种仿体类型（single_layer / multi_layer / eccentric）
- [ ] 散射体球半径 R=0.13m、测量球面半径 R=0.26m，与需求文档数值精确一致
- [ ] 频率范围为 [0.8 GHz, 1.0 GHz]，Fibonacci 方向数=64
- [ ] B-spline 参数化网格为 10×10×5=500 控制点，使用立方 B-spline + PoU 归一化
- [ ] 反演参数完整：eps_tol=1e-3、max_iter=30、n_random_init≥10、mu_init=0.1、mu_max=1.0、c_armijo=0.1、max_backtrack=8
- [ ] ε_r 物理范围限定 [1, 80]，无超界值
- [ ] constraint_regions 字段明确划分 free_optimization_indices（仿体内）与 fixed_indices（仿体外固定 ε_r=1）
- [ ] 仿真配置文档（00-仿真配置.md）包含八大章节（几何定义/真值分布/约束区域/频率观测/B-spline/COMSOL/反演参数/约束模式）
- [ ] config/phantom_config.json JSON 语法合法、字段完整，可被下游脚本无歧义解析
