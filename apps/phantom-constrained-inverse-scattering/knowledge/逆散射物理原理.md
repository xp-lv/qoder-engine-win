本文档为 PhantomConstrainedInverseScattering APP 提供微波逆散射问题的物理基础理论支撑，涵盖 J_obs/J_hyp 的定义与计算、Born 近似、表面等效定理、光锥投影、伴随梯度原理。所有涉及散射场计算的角色（R2 正演、R3 基线反演、R4 约束反演）和评估角色（R5）应参考本文档。

## 1. J_obs 观测数据定义

### 1.1 物理场景

逆散射问题：散射体（半径 R=0.13m）内部具有非均匀介电常数分布 ε_r(r)，在测量球面（半径 R=0.26m）上观测散射电磁场，目标是重建 ε_r(r)。

### 1.2 表面等效定理

从 COMSOL 正演得到的散射场 E^s、H^s，通过表面等效定理投影到 k 空间：

```
J_obs(k̂) = ∫_S [(I-k̂k̂)·(n̂×H^s) + (n̂(E^s·k̂) - E^s(n̂·k̂))/η₀] e^{-ik₀k̂·r} dS
```

其中：
- S 为测量球面（R=0.26m）
- n̂ 为球面外法向量
- η₀ ≈ 377Ω 为自由空间波阻抗
- k₀ = 2πf/c 为自由空间波数
- k̂ 为 Fibonacci 球方向（64 个准均匀方向）
- (I-k̂k̂) 为横向投影算子，消除纵向分量

### 1.3 观测维度

- 每个频率：64 方向 × 3 复分量 = 192 复观测值
- 两个频率（0.8 GHz, 1.0 GHz）：384 复观测值 = 768 实观测值
- **有效独立约束 ≈ 48**（因低频信息冗余，两个相近频率的观测高度相关）

## 2. J_hyp 假设散射场定义

### 2.1 体积等效源

散射体内部的总场 E_total 满足体积等效原理：

```
J_equi(r) = -iωε₀(ε_r(r) - 1)·E_total(r)
```

J_equi 将介质非均匀性的散射效应等效为自由空间中的辐射源。仅散射体内部体素（mask_interior）有非零贡献。

### 2.2 Born 傅里叶变换（光锥投影）

等效源在 k 空间上的投影（一阶 Born 近似）：

```
J_hyp(k̂) = (I-k̂k̂) · Σ_v J_equi(r_v)·ΔV_v·e^{-ik₀k̂·r_v}
```

- 求和遍历散射体内部所有体素 v
- ΔV_v 为体素体积
- 横向投影 (I-k̂k̂) 后得到光锥横向分量 J_hyp_perp

### 2.3 J_hyp 与 J_obs 的关系

- J_obs：COMSOL 原生散射场 → 表面等效定理 → 光锥（"测量值"）
- J_hyp：当前 ε_r 假设 → 体积等效源 → Born FT → 光锥（"预测值"）
- 反演目标：使 J_hyp(ε_r) → J_obs，即最小化 |ΔJ|²

## 3. Born 近似原理

### 3.1 一阶 Born 近似

Born 近似假设散射体内部的场可以用入射场（背景场）近似替代总场。在 J_hyp 计算中，使用的是 COMSOL 正演得到的精确总场 E_total，因此实际上是"精确正演 + Born 投影"，比纯 Born 近似更准确。

### 3.2 适用条件

- 弱散射体（ε_r 对比度低）：Born 近似误差小
- 强散射体（ε_r 对比度高，如水 ε_r≈80 vs 空气 ε_r=1）：Born 近似误差增大
- ka 范围 2.2-2.7（0.8-1.0 GHz，R=0.13m）：中等散射强度

### 3.3 V5a 一致性校验

为验证 Born FT 正演管线的数值正确性，用真值 ε_r_true 正演得到 J_hyp，与 COMSOL 原生 J_obs 比较：

```
V5a: |J_hyp(ε_r_true) - J_obs| / |J_obs| < 5%
```

- **通过**：Born FT 管线数值正确
- **未通过**：正演管线存在数值误差（插值精度、网格分辨率等），正演数据无效

## 4. 光锥投影机制

### 4.1 Fibonacci 球方向

64 个准均匀分布的 k̂ 方向，通过 Fibonacci 螺旋生成：
```
k̂_i = (sin(θ_i)cos(φ_i), sin(θ_i)sin(φ_i), cos(θ_i)),  i = 1..64
```
每个方向的立体角权重 dΩ_i 用于积分。

### 4.2 横向投影

物理上，只有横向（垂直于 k̂）的散射场分量可传播到远场。横向投影算子：
```
J_perp = (I - k̂k̂)·J
```
这是 3×3 的投影矩阵，消除 J 在 k̂ 方向的纵向分量。

## 5. 伴随梯度法物理推导

### 5.1 PDE 约束优化问题

```
min F(ε_r)  s.t.  Maxwell方程 R(E, ε_r) = 0
```

直接对 E 求 ∂E/∂ε_r 不可行（需求解 19268 个灵敏度方程），通过 Lagrange 乘子法消去。

### 5.2 伴随源构造

```
S_raw(v) = Σ_k dΩ_k · ΔJ(k) · e^{-ik₀k̂·r_v}    （k 空间残差逆 FT 回空间域）
f_adj(v) = -2iωε₀(ε_r-1)·ΔV·S_raw(v) / F_obs
```

### 5.3 精确梯度

```
g_direct   = -2ωε₀ΔV·Im{E†·S_raw}      （直接贡献：∂F/∂ε_r|E 固定）
g_indirect = -k₀²ΔV·Re{λ†·E}            （间接贡献：通过 PDE 约束传递）
g(v) = (g_direct + g_indirect) / F_obs
```

- λ 为伴随场，由伴随 Maxwell 方程求解
- 第一项为直接贡献（ε_r 变化对 J_equi 的直接影响）
- 第二项为间接贡献（ε_r 变化导致 E 变化，进而影响 J_equi）

### 5.4 B-spline 链式法则

梯度从体素空间映射到 B-spline 控制点空间：
```
g_c = B_op^T · g_voxel
```
B_op 为 19268×500 的稀疏立方 B-spline 插值矩阵（每行约 64 个非零元素）。

## 6. 多解性问题根源

### 6.1 欠定性分析

- 观测信息量：384 复观测值，但有效独立约束仅 ≈48（两个相近频率的观测高度冗余）
- 未知参数：500 个 B-spline 控制点
- 欠定比：500 / 48 ≈ 10.4（严重欠定）

### 6.2 多解性表现

不同的 ε_r 分布可以产生几乎相同的 J_hyp（J_hyp ≈ J_obs），但 ε_r 分布本身差异很大。表现为：
- 多次随机初始化反演结果方差大（唯一性差）
- 重建 ε_r 分布存在非物理振荡
- 仿体外部区域出现 ε_r ≠ 1 的伪影

### 6.3 仿体约束的解决思路

通过仿体先验几何约束，将有效自由度从 500 降至仿体内部区域控制点数（≈48），使方程组从欠定变为适定/超定。

## 7. 符号约定表

| 符号 | 含义 | 约定 |
|------|------|------|
| 复内积 ⟨a,b⟩ | a†·b | **不取共轭**（即 a·b 而非 conj(a)·b） |
| 梯度下降方向 | -g | 下降方向 = 负梯度 |
| η₀ | 自由空间波阻抗 | ≈ 377Ω |
| k₀ | 自由空间波数 | 2πf/c |
| ε₀ | 真空介电常数 | 8.854×10⁻¹² F/m |
| ω | 角频率 | 2πf |
| F_obs | 归一化常数 | ‖J_obs‖² |

> **关键**：复内积不取共轭的约定已在 2026-06-25 方向性测试中验证。若误取共轭，梯度方向错误，反演发散。
