# 仿体约束正则化方法

## 目的

本文档为 PhantomConstrainedInverseScattering APP 提供仿体先验几何约束的正则化方法论支撑，涵盖硬约束/软约束策略、L-curve 权重选择、空间约束区域定义、B-spline 控制点约束。为仿真配置者（R1）定义约束区域、约束反演执行者（R4）实施约束、对比评估者（R5）评估约束有效性提供统一方法论。

## 适用角色

- 仿真配置者（R1）— 定义约束区域与约束模式
- 约束反演执行者（R4）— 实施硬约束/软约束
- 对比评估者（R5）— 评估约束有效性

---

## 1. 核心问题：多解性与欠定性

### 1.1 问题陈述

无约束反演中，500 个 B-spline 控制点 vs ≈48 个有效独立约束，方程组严重欠定（欠定比 ≈10.4）。导致：
- 反演结果不唯一（多次初始化方差大）
- 仿体外部出现非物理 ε_r 伪影
- 重建精度受限

### 1.2 解决思路

利用仿体提供的已知几何信息（形状、位置、分层结构），将 ε_r 的解空间从 500 维缩小到仿体定义的子空间。

---

## 2. 硬约束策略（默认）

### 2.1 原理

仿体外部区域已知为自由空间（ε_r = 1），因此将仿体外部的 B-spline 控制点**固定**为 ε_r=1，仅优化仿体内部控制点。

### 2.2 实现方式

1. 根据 phantom_config.json 的 constraint_regions 构建布尔掩码：
   ```
   free_mask[i] = True   若控制点 i 位于仿体内部
   free_mask[i] = False  若控制点 i 位于仿体外部
   ```

2. 在每步迭代更新 ε_r 时：
   ```
   g_c(fixed_indices) = 0                    （置零仿体外部梯度）
   ε_r^{(n+1)} = ε_r^{(n)} - μ·g_c           （仅更新内部控制点）
   c(fixed_indices) = 1.0                     （强制固定外部控制点）
   ```

3. 有效自由度 = free_optimization_indices 的数量（预期 ≈48）

### 2.3 优点

- 保证物理一致性：仿体外部严格 ε_r=1，无非物理伪影
- 无需调参：无正则化权重 λ
- 有效自由度大幅降低：从 500 降至 ≈48，方程组从欠定变为适定

### 2.4 潜在风险

- 若仿体几何定义不准确（如边界位置偏差），可能导致内部区域控制点被错误固定
- 过度约束：仿体内部某些区域可能被误判为外部

---

## 3. 软约束策略（可选）

### 3.1 原理

不强制固定仿体外部控制点，而是通过正则化项惩罚仿体外部 ε_r 偏离 1 的程度。

### 3.2 正则化项定义

```
R(ε_r, phantom) = Σ_{v ∉ phantom} |ε_r(v) - 1|²
```

总损失函数：
```
F_total = F(ε_r) + λ · R(ε_r, phantom)
```

### 3.3 梯度修正

```
g_total = g_c + λ · ∂R/∂c
```

其中 ∂R/∂c 对仿体外部控制点施加指向 ε_r=1 的梯度：
```
∂R/∂c_i = 2·λ·(ε_r(control_i) - 1)    若 control_i 位于仿体外部
∂R/∂c_i = 0                            若 control_i 位于仿体内部
```

### 3.4 分层边界约束

对于多层同心球等分层结构，在已知分层边界位置施加跳变约束：
```
R_layer(ε_r) = Σ_{boundaries} |ε_r(r⁺) - ε_r(r⁻) - Δε_expected|²
```

B-spline 节点对齐分层界面。

---

## 4. 硬约束 vs 软约束对比

| 特性 | 硬约束 | 软约束 |
|------|--------|--------|
| 仿体外部 ε_r | 严格 = 1 | 趋近 1（有残差） |
| 物理一致性 | 完美保证 | 近似保证 |
| 调参需求 | 无需调参 | 需选 λ |
| 有效自由度 | 精确控制 | 近似控制 |
| 几何误差敏感性 | 高（几何错误则约束错误） | 低（软性容忍） |
| **默认策略** | **是** | 否（可选） |

### 默认策略约定

APP 默认采用**硬约束**（constraint_mode: "hard"）。软约束作为可选模式，通过 phantom_config.json 中 `constraint_mode: "soft"` 切换。

## 5. L-curve 权重选择方法

### 5.1 方法

对于软约束模式，正则化权重 λ 通过 L-curve 方法确定：

1. 对一系列 λ 值（如 λ = 10⁻⁴, 10⁻³, ..., 10²），分别运行约束反演
2. 记录每次的 log||F(ε_r)||（数据拟合残差）和 log||R(ε_r)||（正则化项）
3. 绘制 log||R|| vs log||F|| 曲线
4. 选取曲线"拐角"（L-curve corner）处的 λ 作为最优值

### 5.2 L-curve 拐角判定

拐角处对应数据拟合与正则化的最佳平衡：
- λ 过小：过拟合，正则化不足
- λ 过大：欠拟合，正则化过度
- 拐角点：最佳权衡

## 6. 约束区域定义规范

### 6.1 phantom_config.json 的 constraint_regions 字段

```json
{
  "constraint_regions": {
    "free_optimization_indices": [12, 13, 14, ..., 47],
    "fixed_indices": [0, 1, ..., 11, 48, ..., 499],
    "boundary_indices": [11, 47],
    "phantom_sdf": { "type": "sphere", "center": [0,0,0], "radius": 0.13 }
  }
}
```

- `free_optimization_indices`：仿体内部可自由优化的 B-spline 控制点索引
- `fixed_indices`：仿体外部固定 ε_r=1 的控制点索引
- `boundary_indices`：位于仿体边界附近的控制点（分层约束可能涉及）
- `phantom_sdf`：符号距离函数定义，用于判断控制点是否在仿体内部

### 6.2 控制点分类方法

对于每个 B-spline 控制点 c_i（空间坐标 r_i）：
1. 计算 SDF(r_i)：若 SDF < 0 则在仿体内部（free），若 SDF > 0 则在仿体外部（fixed）
2. 多层球：检查 r_i 位于哪一层，对应不同的约束策略
3. 偏心结构：使用复合 SDF（主球 + 偏心球的并集）

## 7. 正则化效果理论分析

### 7.1 自由度计算

- 无约束：500 个自由 B-spline 控制点
- 硬约束后：仅 free_optimization_indices 数量个自由度
- 对于单层均匀球（R=0.13m），仿体内部约包含 10×10×5 控制点网格的 ≈48 个点
- 适定性改善：48 自由度 vs 48 有效约束 → 适定方程组

### 7.2 约束有效性预期

| 指标 | 无约束基线 | 硬约束预期 |
|------|-----------|-----------|
| ε_r 重建误差 | 高（多解性） | 低（唯一解） |
| 多初始化方差 | 大 | 小 |
| 仿体外部 ε_r | ≠1（伪影） | =1（精确） |
| 收敛迭代数 | 多（搜索空间大） | 少（搜索空间小） |

---

## 8. 约束有效性评估方法

### 8.1 评估维度

对比评估者（R5）应从以下维度评估约束有效性：

1. **重建精度改善**：ε_r_err_constrained vs ε_r_err_baseline（需求 S1）
2. **唯一性改善**：var_constrained vs var_baseline（需求 S2）
3. **约束生效验证**：仿体外部 ε_r 均值 ∈ [0.95, 1.05]（需求 S3）
4. **物理合理性**：所有 ε_r ∈ [1, 80]（需求 S4）

### 8.2 有效自由度验证

- 硬约束后有效自由度 ≈ free_optimization_indices 的数量
- 若有效自由度仍远大于 48，说明约束区域定义不合理（仿体内部过大）
