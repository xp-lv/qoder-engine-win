# 伴随梯度反演算法

## 目的

本文档为 PhantomConstrainedInverseScattering APP 提供 INVERSE_SCATTER3.0 的 9 步伴随迭代反演算法详细说明，涵盖迭代循环结构、Armijo 线搜索、B-spline 参数化、收敛判断、步长策略、约束反演修改。为基线反演执行者（R3）和约束反演执行者（R4）提供算法实现支撑。

## 适用角色

- 基线反演执行者（R3）— 无约束 9 步迭代循环
- 约束反演执行者（R4）— 带约束修改的 9 步迭代循环

---

## 1. 损失函数定义

```
F(ε_r) = (1/N_k) Σ_k |ΔJ_k|² / |J_obs_k|²
```

- N_k = 64（Fibonacci 方向数）
- ΔJ_k = J_obs_perp(k) - J_hyp_perp(k)（残差）
- 归一化：每个方向的残差除以该方向的观测值范数
- 收敛条件：√F < eps_tol（eps_tol = 1e-3）

---

## 2. B-spline 参数化

### 2.1 控制点网格

3D 立方 B-spline，10×10×5 = 500 控制点：
```
c ∈ ℂ^500  →  B_op  →  ε_r ∈ ℂ^19268 (体素空间)
```

### 2.2 B_op 插值矩阵

- B_op: 19268×500 稀疏矩阵
- 立方 B-spline 基函数，每行约 64 个非零元素
- 行归一化：保证 PoU（分区统一性）= 1.0 在边界处
- 映射公式：ε_r = B_op · c

### 2.3 链式法则（梯度映射）

体素空间梯度 → 控制点空间梯度：
```
g_c = B_op^T · g_voxel
```

## 3. 9 步迭代循环（详细）

### 准备阶段

```
config → 加载 COMSOL 模型 → 建立体素网格 → 设置背景场
初始化: c = ones(500, 1)  （ε_r = 1, 自由空间）
```

### 第 ① 步 — COMSOL 正演求解

```
ε_r = B_op · c
update_epsilon(model, ε_r)        ← int2/int3 写入 COMSOL
model.study('std1').run           ← 频域散射场求解
E_total = read_field(model, voxel.pos)    ← mphinterp 提取 [N_in × 3]
```

### 第 ② 步 — 计算等效源

```
J_equi(r_v) = -iωε₀(ε_r(r_v) - 1) · E_total(r_v)
```
仅散射体内部体素（mask_interior）有非零贡献。

### 第 ③ 步 — Born FT + 横向投影 → J_hyp

```
J_hyp(k̂) = (I-k̂k̂) · Σ_v J_equi(r_v) · ΔV_v · e^{-ik₀k̂·r_v}
```
对 64 个 Fibonacci 方向逐一计算，然后横向投影。

### 第 ④ 步 — 计算残差

```
ΔJ = J_obs_perp - J_hyp_perp
```
均在光锥横向空间。

### 第 ⑤ 步 — 收敛判断

```
F = (1/N_k) Σ_k |ΔJ_k|² / |J_obs_k|²
√F < eps_tol (1e-3)?
```
- **是**：跳出循环，反演成功收敛
- **否**：继续第 ⑥-⑨ 步

### 第 ⑥ 步 — 构建伴随源

```
S_raw(v) = Σ_k dΩ_k · ΔJ(k) · e^{-ik₀k̂·r_v}     （k 空间残差逆 FT 回空间域）
f_adj(v) = -2iωε₀(ε_r-1) · ΔV · S_raw(v) / F_obs
```
- S_raw 是测量残差回投到体素空间的场
- f_adj 是伴随 Maxwell 方程的源项

### 第 ⑦ 步 — COMSOL 伴随求解 → λ

```
写入 6 个插值函数（f_adj 的分量）
创建 External_current_density (vec1)
禁用散射场背景 (sctr1)
model.study('std1').run    ← 复用正演 LU 分解求解伴随场
λ = read_field(model, voxel.pos)    ← 提取伴随场 [N_in × 3]
恢复模型状态（重启用 sctr1，移除 vec1）
```

### 第 ⑧ 步 — 计算精确梯度

```
g_direct   = -2ωε₀ΔV · Im{E† · S_raw}       （直接贡献）
g_indirect = -k₀²ΔV · Re{λ† · E}             （间接贡献）
g(v) = (g_direct + g_indirect) / F_obs
```

**关键符号约定**：
- 复内积 ⟨a,b⟩ = a·b（**不取共轭**，即 a†b 而非 conj(a)·b）
- 下降方向 = **-g**（负梯度方向）

链式法则映射到控制点空间：
```
g_c = B_op^T · g_voxel    [500 × 1]
```

### 第 ⑨ 步 — Armijo 线搜索 → 更新 ε_r

```
RMS 归一化梯度
μ = mu_init (0.1)
while not (Armijo 条件满足) and (回溯次数 < 8):
    c_new = c - μ · g_c
    ε_r_new = B_op · c_new
    物理约束: clip(ε_r_new, 1, 80)
    正演验证 F_new < F_old - c_armijo · μ · ||g||²
    if 不满足: μ = μ × 0.5
    if 满足: c = c_new, μ = min(μ × 2, mu_max)

自适应步长: if std(ε_r) > 0.3: μ = μ × 0.5
```

更新后：c^{(n+1)} = c^{(n)} - μ · g_c

---

## 4. Armijo 线搜索参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| mu_init | 0.1 | 初始步长（降低避免分布破裂） |
| mu_max | 1.0 | 最大步长 |
| ls_decay | 0.5 | 回溯衰减因子 |
| c_armijo | 0.1 | Armijo 常数（增大使条件更易满足） |
| ls_max_trials | 8 | 最大回溯次数 |
| ε_r 物理范围 | [1, 80] | 线搜索约束 |

### 自适应步长

若 `std(ε_r) > 0.3`（分布不均匀），步长缩小 50%，避免非均匀分布导致梯度方向恶化。

## 5. 约束反演迭代修改（R4 专用）

约束反演的 9 步循环与基线完全相同，**唯一差异在第 ⑨ 步**：

### 硬约束模式

在第 ⑨ 步更新 ε_r 前：
```
g_c(fixed_indices) = 0                  ← 置零仿体外部梯度
c_new = c - μ · g_c                     ← 仅更新内部控制点
c_new(fixed_indices) = 1.0              ← 强制固定外部控制点
```

### 软约束模式

在第 ⑧ 步梯度计算后、第 ⑨ 步前：
```
g_total = g_c + λ · ∂R/∂c
其中 ∂R/∂c_i = 2λ(ε_r(c_i) - 1)  for i ∈ fixed_indices
```

## 6. 收敛判据与失败处理

### 成功收敛

- √F < eps_tol (1e-3)，在 ≤30 次迭代内
- 需求 F3（基线）/ F4（约束）：≤30 次迭代内收敛

### 失败处理

- 超过 30 次迭代仍未收敛：标记 converged = false
- Armijo 线搜索 8 次回溯均失败：步长过小，可能卡在鞍点
- COMSOL 求解超时：从检查点恢复续算

### 检查点续算

每步迭代保存：
- 当前 ε_r（B-spline 控制点 c）
- 迭代步号
- 当前 F 值
- 约束掩码（R4）

## 7. 多次随机初始化唯一性测试

### 测试目的

验证反演结果的唯一性——多次独立初始化是否收敛到相同解。

### 测试方法

1. 至少 10 次独立随机初始化（需求 S2：≥10 次）
2. 每次使用不同随机种子初始化 B-spline 控制点
3. 基线反演（R3）：全部 500 控制点随机初始化
4. 约束反演（R4）：仅仿体内部控制点随机初始化，外部固定 ε_r=1
5. 统计 10 次结果的方差

### 唯一性指标

```
var = Var(ε_r_recon^{(i)}),  i = 1..10
```
方差越小越唯一。预期：
- 基线方差大（多解性）
- 约束方差小（约束改善唯一性）
- 验收标准 S2：var_constrained < var_baseline
