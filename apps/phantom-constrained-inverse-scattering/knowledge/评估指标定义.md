# 评估指标定义

## 目的

本文档为 PhantomConstrainedInverseScattering APP 提供对比评估五项量化指标的精确定义、计算公式、判定标准。为对比评估者（R5）计算指标、结果审计者（R6）检验指标合理性提供统一参考标准。

## 适用角色

- 对比评估者（R5）— 计算五项指标，生成评估报告
- 结果审计者（R6）— 审查指标合理性，防范统计陷阱

---

## 1. 指标 1 — ε_r 重建误差（相对 L2 误差）

### 定义

```
ε_r_err = ‖ε_r_recon - ε_r_true‖₂ / ‖ε_r_true‖₂
```

### 计算要点

- **分母为真值范数** ‖ε_r_true‖₂，不是重建值范数
- ε_r_recon 和 ε_r_true 均为体素空间的复数分布 [19268×1]
- L2 范数：‖x‖₂ = √(Σ|x_i|²)
- 分别计算基线和约束两组：
  - `ε_r_err_baseline = ‖ε_r_recon_baseline - ε_r_true‖₂ / ‖ε_r_true‖₂`
  - `ε_r_err_constrained = ‖ε_r_recon_constrained - ε_r_true‖₂ / ‖ε_r_true‖₂`

### 验收标准

- **S1**：ε_r_err_constrained < ε_r_err_baseline（约束降低重建误差）

### 常见错误

- ❌ 分母误用重建值：‖ε_r_recon - ε_r_true‖₂ / ‖ε_r_recon‖₂ → 误差被低估
- ❌ 使用标量 ε_r 而非空间分布 → 无法反映分布误差

---

## 2. 指标 2 — 收敛速度（迭代次数）

### 定义

```
n_iter = 达到 √F < eps_tol 所需的迭代次数
```

### 计算要点

- 从 convergence_history 中提取首次满足 √F < 1e-3 的迭代步号
- 分别记录基线和约束：
  - `n_iter_baseline`
  - `n_iter_constrained`
- **必须在相同初始条件下对比**（相同初始 ε_r、相同步长参数）

### 公平对比要求

- 基线和约束反演使用相同的初始 ε_r = 1（均匀自由空间）
- 相同的 Armijo 线搜索参数（mu_init=0.1, c_armijo=0.1 等）
- 相同的最大迭代次数（30）
- 唯一差异：约束反演施加了仿体约束

## 3. 指标 3 — 唯一性指标（多初始化方差）

### 定义

```
var = Var({ε_r_recon^{(i)}}, i=1..N_init)
```

### 计算要点

- N_init ≥ 10（需求 S2：至少 10 次独立随机初始化）
- 每次使用**不同的随机种子**初始化 B-spline 控制点
- 方差计算：对体素空间每个体素位置，统计 N_init 次重建值在该位置的方差
  ```
  var(v) = (1/N_init) Σ_i |ε_r_recon^{(i)}(v) - mean(v)|²
  ```
- 总体方差指标：`Var_total = mean_v(var(v))` 或 `‖var‖₂`

### 验收标准

- **S2**：var_constrained < var_baseline（约束改善唯一性）

### 常见错误

- ❌ 初始化次数不足（< 10 次）
- ❌ 随机种子相同（结果完全相同，方差 = 0 是假象）
- ❌ 仅报告标量方差（如最终 F 值的方差），而非 ε_r 空间分布方差

---

## 4. 指标 4 — 约束有效性（误差降低百分比）

### 定义

```
improvement = (ε_r_err_baseline - ε_r_err_constrained) / ε_r_err_baseline × 100%
```

### 计算要点

- 直接使用指标 1 的两组误差值
- 正值表示约束降低了误差（有效），负值表示约束增加了误差（无效）
- 预期：正值，且改善幅度具有实际意义（> 10%）

---

## 5. 指标 5 — J_hyp 拟合度（最终残差）

### 定义

```
residual = |J_hyp_final - J_obs| / |J_obs|
```

### 计算要点

- J_hyp_final 为反演收敛后用重建 ε_r 计算的最终 J_hyp
- 分别计算基线和约束：
  - `residual_baseline`
  - `residual_constrained`
- 反映正问题一致性（J_hyp 是否成功拟合 J_obs）

### 合理性检查

- 残差应与收敛阈值 √F 一致（√F < 1e-3 → residual ≈ √F 量级）
- 残差异常小（< 1e-6）可能表示过拟合
- 残差异常大（> 0.1）可能表示未收敛

## 6. 科学验证层验收标准汇总

| 标准 | 定义 | 判定方法 |
|------|------|----------|
| S1 | 约束反演的 ε_r 重建相对 L2 误差 < 无约束基线 | ε_r_err_constrained < ε_r_err_baseline |
| S2 | 约束反演的多初始化方差 < 无约束基线 | var_constrained < var_baseline（≥10 次初始化） |
| S3 | 仿体外部区域 ε_r ≈ 1（约束生效） | 仿体外部 ε_r 均值 ∈ [0.95, 1.05] |
| S4 | 重建结果无非物理值 | 所有 ε_r ∈ [1, 80] |

## 7. 统计陷阱防范

### 7.1 Cherry-picking 偏差

**问题**：多初始化测试中只报告最好的结果（误差最小的初始化），夸大约束效果。

**防范**：
- 报告全部 N_init 次结果，或报告中位数
- 在评估报告中明确标注每次初始化的结果
- 对比应基于中位数或平均值，而非最优值

### 7.2 不公平对比

**问题**：基线和约束使用了不同的初始条件或超参数，对比不公平。

**防范**：
- comparison_conditions 字段明确声明初始条件一致性
- 相同初始 ε_r、相同步长、相同最大迭代数
- 唯一差异：是否有仿体约束

### 7.3 初始化独立性验证

**问题**：多次初始化使用了相同的随机种子，结果完全相同，方差 = 0 是假象。

**防范**：
- 每次使用不同的随机种子（如 seed = 1, 2, ..., 10）
- 在评估报告中记录每次初始化的种子
- 验证不同初始化产生了不同的收敛路径

### 7.4 样本量不足

**问题**：仅在 1 种仿体类型上验证，结论不具备泛化性。

**防范**：
- 在评估报告中明确声明验证范围（仅单一仿体）
- 建议在多种仿体类型上重复验证
- 审计者（R6）应关注泛化性担忧

- 三列布局：基线重建 | 约束重建 | 真值

- 标注收敛阈值线（√F = 1e-3）

- 多初始化的 ε_r 重建误差直方图
- 两组分布：基线 vs 约束

## 检查清单

R5 计算指标时自检：
- [ ] 五项指标全部有定量数值输出（需求 F5）？
- [ ] 指标 1 分母为真值范数？
- [ ] 指标 2 在相同初始条件下对比？
- [ ] 指标 3 使用 ≥10 次不同随机种子的初始化？
- [ ] S1-S4 验收标准逐项判定？

- [ ] 是否存在 cherry-picking？
- [ ] 初始条件是否一致？
- [ ] 初始化是否真正独立？
- [ ] 泛化性担忧是否记录？
