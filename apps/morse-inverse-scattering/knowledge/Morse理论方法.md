# Morse 理论方法

> 本文档是 morse-inverse-scattering App 的核心方法论文档，为临界点分析、降阶反演、拓扑重建及对抗审查提供理论支撑。

---

## 一、目的

本文档解决以下问题：
- 如何将介电常数分布 ε_r(r) 视为 Morse 函数并进行临界点检测？
- 如何用 Morse 指标与 Morse-Smale 复形刻画 ε_r 分布的拓扑结构？
- 如何用 Morse 不等式为反演收敛提供理论下界？
- 如何用临界点参数化将 ~500 个未知数降至 ~20-50 个？

---

|------|----------|

## 三、核心内容

### 3.1 Morse 函数定义

**定义**：设 f: M → ℝ 是定义在紧致流形 M 上的光滑函数。若 f 的所有临界点（∇f = 0 的点）都是**非退化**的（即 Hessian 矩阵在临界点处的行列式 ≠ 0），则称 f 为 **Morse 函数**。

**ε_r 作为 Morse 函数的物理合理性**：
- 介电常数分布 ε_r(r) 在球域 B³ 上是连续光滑的物理场。
- 实际目标（如西瓜：瓜瓤/瓜籽/瓜皮分层）的 ε_r 分布具有明确的分层结构，其临界点数量很少（~20-50），且通常非退化。
- 将 ε_r 视为 Morse 函数意味着：ε_r 的拓扑结构完全由其（有限个）临界点编码。

### 3.2 临界点检测算法

临界点是梯度为零的点：∇ε_r = 0。

**数值求解方法**：
1. **Finite Difference 梯度计算**：在离散网格上用中心差分计算 ∂ε_r/∂x, ∂ε_r/∂y, ∂ε_r/∂z。
2. **Finite Element 梯度计算**：在 FEM 网格上用形函数导数计算梯度。
3. **零点搜索**：对梯度场 ∇ε_r 搜索零点，常用 Newton 迭代或网格细分法。
4. **阈值选取**：设 |∇ε_r| < ε_thresh（小阈值）作为候选临界点判据，再精化定位。

**非退化性验证**：对每个候选临界点计算 Hessian 矩阵 H（二阶偏导数），验证 det(H) ≠ 0。退化点（det(H) = 0）需剔除或做微扰处理。

### 3.3 Morse 指标（index）计算

**定义**：临界点 p 处的 Morse 指标 index(p) 是 Hessian 矩阵 H(p) 的**负特征值个数**。

| Morse 指标 | 几何含义 | ε_r 分布中的物理对应 |
|-----------|----------|---------------------|
| 0 | 极小值 | ε_r 局部最低点（如空气腔、低介电区域） |
| 1 | 鞍点（1 负方向） | ε_r 在一个方向递减、两个方向递增的过渡区 |
| 2 | 鞍点（2 负方向） | ε_r 在两个方向递减、一个方向递增的过渡区 |
| 3 | 极大值 | ε_r 局部最高点（如高含水瓜瓤中心） |

**计算步骤**：
1. 在临界点 p 处计算 Hessian 矩阵 H(p)（3×3 对称矩阵）。
2. 求 H(p) 的三个特征值 λ₁, λ₂, λ₃。
3. 统计负特征值个数 = Morse 指标。

### 3.4 Euler 示性数校验

**Morse 理论核心定理**：对紧致流形 M 上的 Morse 函数 f，有

$$\sum_{k=0}^{n} (-1)^k \cdot m_k = \chi(M)$$

其中 m_k 是 Morse 指标为 k 的临界点数，χ(M) 是 M 的 Euler 示性数。

**球域 B³ 的 Euler 示性数**：χ(B³) = 1。

**校验方法**：
- 统计各指标临界点数：m₀（极小）、m₁（鞍点1）、m₂（鞍点2）、m₃（极大）。
- 计算 Σ(-1)^k × m_k = m₀ - m₁ + m₂ - m₃。
- 与 χ(B³) = 1 比较。若相等，说明临界点清单拓扑完备；若不等，存在遗漏或多算。

> **拓扑红队核心审查工具**：Euler 示性数校验是检验临界点清单完备性的最直接工具。

### 3.5 Morse-Smale 复形构建

**稳定流形** W^s(p)：沿梯度流下降到临界点 p 的所有点的集合。
**不稳定流形** W^u(q)：沿梯度流上升（逆梯度）离开临界点 q 的所有点的集合。

**Morse-Smale 条件**：对所有临界点对 (p, q)，稳定流形 W^s(p) 与不稳定流形 W^u(q) **横截相交**（transversal intersection）。

**复形胞腔**：满足 Morse-Smale 条件时，稳定流形 {W^s(p)} 构成流形 M 的一个胞腔分解，称为 **Morse-Smale 复形**。每个胞腔对应一个临界点，胞腔的维度等于该临界点的 Morse 指标。

**自适应区域划分**：Morse-Smale 复形的胞腔自然地将球域 B³ 划分为若干拓扑区域，每个区域内的 ε_r 单调变化，这为后续拓扑重建提供了自适应区域约束。

### 3.6 Morse 不等式

**弱不等式**：对每个 k，临界点数满足
$$m_k \geq \beta_k$$
其中 β_k 是流形 M 的第 k 个 Betti 数。

**球域 B³ 的 Betti 数**：β₀ = 1（连通）、β₁ = 0、β₂ = 0、β₃ = 1（可定向紧致 3-流形）。

**强不等式**：
$$\sum_{k=0}^{n} (-1)^k m_k = \chi(M) = \sum_{k=0}^{n} (-1)^k \beta_k$$

**反演收敛下界的理论保障**：Morse 不等式 m_k ≥ β_k 为临界点数提供了下界，意味着参数空间不会无限膨胀。强不等式提供拓扑约束，确保参数空间的结构合理性。这为适定性审查者评估反问题适定性提供了理论依据。

### 3.7 临界点参数化策略

**传统方法**：全域 B 样条参数化，~500 个控制点 → 500 个连续未知数 vs ~48 个独立约束 → 严重欠定。

**Morse 降阶参数化**：每个临界点由以下参数描述：
- 位置 (x, y, z)：3 个连续参数
- 值 ε_r：1 个连续参数
- Morse 指标：离散量（0/1/2/3），不计入连续未知数

**参数空间维度**：~20-50 个临界点 × 4 = ~80-200 个连续参数。
与 ~48 个独立约束对比，超定比显著改善（从 ~0.1 提升至 ~0.3-0.6）。

### 3.8 从离散临界点重建连续场的插值原理

**重建流程**：
1. **RBF 插值初值**：以临界点为插值中心，用径向基函数（RBF）插值得到初始全域场。
2. **Morse-Smale 复形区域约束**：每个复形胞腔内使用局部 RBF 插值，保证胞腔内单调性。
3. **PoU 条件平滑**：单位分解（Partition of Unity）权重融合各胞腔局部插值，保证全域连续性。
4. **边界连续性**：胞腔边界强制 C⁰ 或 C¹ 连续。

## 四、示例

### 示例：西瓜 ε_r 分布的临界点分析

假设西瓜 ε_r 分层结构：瓜皮（ε_r~2）、瓜瓤（ε_r~65）、瓜籽区（ε_r~3）。

**预期临界点**（简化）：
| # | 位置 | ε_r 值 | Morse 指标 | 类型 |
|---|------|--------|-----------|------|
| 1 | 中心 | 65 | 3 | 极大值（瓜瓤中心） |
| 2 | 瓜皮附近 | 2 | 0 | 极小值（瓜皮） |
| 3-6 | 分层过渡区 | ~30 | 1 或 2 | 鞍点 |

**Euler 校验**：m₀ - m₁ + m₂ - m₃ = 2 - 2 + 2 - 1 = 1 = χ(B³) ✓

**参数数**：6 临界点 × 4 = 24 个连续参数（vs 传统 500），超定比 48/24 = 2.0（适定）。

## 五、检查清单

### 临界点分析者自检
- [ ] 所有临界点是否经过非退化性验证（det(H) ≠ 0）？
- [ ] Morse 指标是否正确计算（Hessian 负特征值个数）？
- [ ] Euler 示性数校验是否通过（Σ(-1)^k m_k = 1）？
- [ ] Morse 不等式是否满足（m_k ≥ β_k）？
- [ ] Morse-Smale 复形横截相交条件是否验证？

### 拓扑红队审查清单
- [ ] 是否独立重算 Euler 示性数？
- [ ] 是否检查遗漏的鞍点（低对比度区域）？
- [ ] 是否逐点复核 Morse 指标？

### 适定性审查者审查清单
- [ ] 临界点参数数是否接近独立约束数？
- [ ] Morse 不等式是否提供有效收敛下界？
