# 基线资产参考

## 1. 固化基线（baseline/metrics_baseline.json 只读消费）

基线是科研对比的参照原点。**基线不可漂移**——只读消费，绝不写入或修改。

## 2. 基线格式（baseline/metrics_baseline.json）

```json
{
  "cos_theta_baseline": 0.9929,
  "f_cheb_baseline": 0.091,
  "a12_pass_baseline": "5/7",
  "c01_pass_baseline": "4/6",
  "created": "2026-07-03",
  "source_exp": "verify_forward_pipeline",
  "locked": true
}
```

## 3. Δ 计算规则

Δ = 迭代值 − 基线值（三件套各自独立计算）

| 指标 | 迭代值 | 基线值 | Δ 示例 |
|------|--------|--------|--------|
| cos θ | 0.9935 | 0.9929 | +0.0006（正向） |
| F_cheb | 0.082 | 0.091 | −0.009（正向，残差下降是好事） |
| A12 PASS | 6/7 | 5/7 | +1（正向） |

## 4. exceeds_baseline 判定

exceeds_baseline = true 当且仅当：
- cos θ Δ ≥ 0（方向正确）
- 且至少一个维度的 Δ 是严格正向（cos θ 提升 或 F_cheb 下降 或 PASS 增加）

## 5. 注意事项

- 基线文件缺失或格式异常时报 fail
- 基线被修改（locked != true）时报 fail
- Δ 计算失败（数据缺失）报 fail
