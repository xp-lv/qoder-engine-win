# 实验执行手册

> 注入目标：实验执行者（M3）、管线优化者（M6）
> 用途：提供调用 COMSOL/pipline 的具体命令模板、环境检查方法和最小复现代码

## 目的

本文档解决 role-executor 执行 M3/M6 时"不知道怎么调 MATLAB、怎么检查 mphserver、怎么跑 pipline"的问题。所有命令均经过 2026-07-03 实跑验证。

## 核心准则

### 1. 环境前置检查（每次实验前必做）

**检查 COMSOL mphserver 是否在运行**（port 2036）：
```powershell
powershell -Command "Test-NetConnection localhost -Port 2036"
# 看 TcpTestSucceeded = True 即可
```

如果 mphserver 未运行，**不要自动启动**（mphserver 须独立终端长期运行），报告 `E_MPH_UNREACHABLE` 并提示：
```
请在独立终端启动 COMSOL mphserver:
& "D:\LenovoSoftstore\Install\COMSOL62\Multiphysics\bin\win64\comsolmphserver.exe" -port 2036
```

**检查 MATLAB 可执行文件存在**：
```powershell
Test-Path "D:\LenovoSoftstore\Install\MATLAB\bin\matlab.exe"
```

**检查 pipline 根目录存在**：
```powershell
Test-Path "d:\ZJU\PROJECT\2026-07-02-qoder-engine\COMSOL\pipline\config\config.m"
```

### 2. MATLAB 调用命令模板

pipline 的所有脚本都通过 MATLAB -batch 模式调用。**必须显式 addpath config 和 experiment**（否则 setup() 找不到路径）。

**模板 A：正演验证（verify_forward_pipeline）**
```powershell
cd "d:\ZJU\PROJECT\2026-07-02-qoder-engine\COMSOL\pipline"
& "D:\LenovoSoftstore\Install\MATLAB\bin\matlab.exe" -batch "addpath('config','experiment'); verify_forward_pipeline"
```
耗时约 30 秒，产出 10 步检查结果（V5a / cos θ / F_cheb 等）。

**模板 B：完整反演（以 A12 算法为例）**
```powershell
cd "d:\ZJU\PROJECT\2026-07-02-qoder-engine\COMSOL\pipline"
& "D:\LenovoSoftstore\Install\MATLAB\bin\matlab.exe" -batch "addpath('config','experiment','algorithm'); A12_multi_freq_inversion"
```
耗时约 2-5 分钟，产出反演结果至 `data/results/`。

**模板 C：参数化正演（最小复用代码，适用于 M3 实验执行）**
```matlab
% --- 保存为 experiment/<exp_id>/run_forward.m 并在 MATLAB 中执行 ---
setup();                          % 自动 addpath config/utils/core_*/algorithm
p = config();
mphstart(2036);
model = mphload(p.comsol_model_path);

% 提取网格
voxel = fem_mesh_utils(model, p, p.a_scatter);

% 设真值（根据假设调整）
voxel.epsilon_r(voxel.mask_interior) = 5.0;  % ← 根据 M2 的假设修改

% 正演
[E_total, ~, E_gauss] = solve_forward(model, voxel, p);

% J_obs (COMSOL 原生)
grid = build_measurement_grid(p);
sf = extract_scattered(model, grid);
lc = lightcone_project(grid, sf, p);
J_obs = lc.J_obs_perp;

% J_hyp (Born 近似)
J_equi = equivalent_source(voxel, E_total, p);
lc.k_vec = p.k0 * lc.k_dir;
J_hyp = lightcone_hyp(voxel, J_equi, lc, p);

% 计算 F_k
F_k = sum(abs(J_obs - J_hyp).^2, 2) ./ sum(abs(J_obs).^2, 2) / 6;
fprintf('max F_k = %.4e\n', max(F_k));
fprintf('cos theta = %.4f\n', mean(dot(J_obs, J_hyp, 2) ./ (vecnorm(J_obs,2,2) .* vecnorm(J_hyp,2,2))));
```

### 3. 实验子目录结构与 pipline 的关系

M3 创建的 `experiment/<exp_id>/` 子目录 **在 APP 工作区内**，不是 pipline 的 experiment/ 目录。两者的关系：
- pipline 的 `experiment/`：pipline 自带的验证脚本（verify_forward_pipeline.m 等），只读
- APP 的 `experiment/<exp_id>/`：M3 为每次实验创建的独立子目录，含 config_snapshot.json / l1_snapshot/ / log.md / 结果文件

M3 调用 pipline 跑实验后，把结果**复制到** APP 的 `experiment/<exp_id>/` 下。

### 4. 补丁后验证命令（M6 专用）

M6 打完性能/正确性补丁后，必须运行正演管线验证脚本确认补丁不破坏正确性：
```powershell
cd "d:\ZJU\PROJECT\2026-07-02-qoder-engine\COMSOL\pipline"
& "D:\LenovoSoftstore\Install\MATLAB\bin\matlab.exe" -batch "addpath('config','experiment'); verify_forward_pipeline"
```

验证标准（2026-07-03 基线）：
- cos θ > 0.99（方向一致性）
- |J_obs|/|J_hyp| ≈ 1.0（幅值一致性）
- max F_k < 0.05（Born 近似固有偏差，非管线 bug）

如果补丁后 cos θ < 0.99 或 |J_obs|/|J_hyp| 偏离 1.0，说明补丁破坏了正确性，必须回退。

### 5. mphserver 连接管理

- **并发正演 ≤ 1**：mphserver 默认单实例，同时只能跑一个正演
- **重连策略**：最多 3 次重试，间隔 5 秒
- **3 次失败后**：报告 `E_MPH_UNREACHABLE`，中止实验

## 判别清单

- [ ] 实验前是否检查了 mphserver port 2036 可达？
- [ ] MATLAB -batch 命令是否显式 addpath('config','experiment')？
- [ ] 实验结果是否从 pipline 复制到 APP 的 experiment/<exp_id>/？
- [ ] M6 补丁后是否运行了 verify_forward_pipeline 验证正确性？
- [ ] config_snapshot.json 的物理参数是否从 config.m 读取而非手写？
- [ ] git tag exp_<exp_id> 是否已标记？

## 反模式

- ❌ 不检查 mphserver 直接调 MATLAB（mphstart 超时崩溃，无明确错误）
- ❌ MATLAB -batch 不加 addpath('config','experiment')（setup() 找不到路径，函数未定义错误）
- ❌ 把实验结果留在 pipline 的 data/results/ 而不复制到 APP experiment/（实验不可追溯）
- ❌ M6 打补丁后不跑 verify_forward_pipeline（正确性回归未检测）
- ❌ 同时启动 2 个正演（mphserver 单实例，第二个会 Connection refused）
- ❌ 忘记执行 git tag 标记代码版本（实验不可追溯）
